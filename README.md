# Project Portfolio Manager

Single-file web app (`index.html`) built on the A-A framework (vanilla HTML/CSS/JS, Public Sans, TfNSW palette: navy `#002664`, waratah red `#D7153A`).

- **Projects**: Active Projects and Future Pipeline lists with counts; View/Edit or double-click opens details.
- **Project tabs** (red underline): Details, Resource, Schedule, Invoice Milestones, Risks, Audit.
- **Resources**: per-person allocations by project/phase/date range, editable; overlapping allocations over 100% are red.
- **Risks**, **Invoice Milestones**, **Audit Log**: portfolio-wide views.

Open `index.html` in a browser; data is stored in `localStorage`. GitHub Pages: enable Pages on `main` for a hosted demo.
